# 이타카로의 귀환 · 도장 기록 백엔드

[이타카로의 귀환](https://h-yun-park.github.io/return-to-ithaca/) 사이트에서 선원이 부스 코드를 넣으면, 이름과 도장 기록이 구글 시트에 쌓여요. 운영진은 시트를 보고 출석 구글폼(도장판 사진)과 이중으로 확인할 수 있어요.

## 동작 방식

1. 선원이 사이트에 처음 들어올 때 이름과 학번을 적어요. 학번 1개가 선원 1명이에요.
2. 부스 활동을 마치면 RA가 그 부스의 4자리 코드를 알려 줘요.
3. 선원이 부스 페이지에 코드를 넣으면 시트의 `선원` 탭에 도장 시각이 찍혀요.
4. 같은 선원이 코드를 10분 안에 5번 틀리면 잠시 막혀요.

## 시트 구성

| 탭 | 내용 |
|---|---|
| 선원 | 학번 1개당 1줄: 학번, 이름, 도장 수, 이타카 자격(7개 이상이면 O), 부스별 도장 시각 |
| 부스코드 | 부스별 4자리 코드. 직접 바꿔도 바로 반영돼요 |
| 기록 | 모든 도장 시도 로그(성공, 이미 받음, 코드 틀림) |

## 현재 연결 상태

- 기록 시트: 구글 드라이브의 `이타카로의 귀환 도장 기록` (`Code.gs`의 `SHEET_ID`)
- 스크립트: script.google.com의 `이타카로의 귀환 도장 기록` 프로젝트 (독립 실행형)
- 웹 앱 URL은 `return-to-ithaca` 레포 `index.html`의 `const API`에 들어가 있어요.

## 새로 설치할 때

1. 구글 시트를 만들고 주소의 `/d/`와 `/edit` 사이 ID를 `Code.gs`의 `SHEET_ID`에 넣어요.
2. script.google.com에서 새 프로젝트를 만들고 `Code.gs`를 붙여 넣어요.
3. `setup`을 실행하고 권한을 허용해요. 시트에 `선원`, `부스코드`, `기록` 탭이 생겨요.
4. **배포 → 새 배포 → 웹 앱**, 실행: **나**, 액세스: **모든 사용자**로 배포해요.
5. 나온 웹 앱 URL을 `index.html`의 `const API=''`에 넣어요.

`Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영돼요. URL은 그대로예요.

## 운영 팁

- 부스 코드는 `부스코드` 탭에만 있어요. 이 레포나 사이트에는 들어가지 않아요. RA에게만 공유하세요.
- 행사 당일 코드가 새어 나가면 `부스코드` 탭에서 바꾸면 돼요.
- 동명이인은 학번으로 구분돼요. 휴대폰을 바꿔도 같은 학번으로 등록하면 도장이 이어져요.
- 같은 학번으로 이름을 다시 등록하면 이름만 바뀌고 도장은 유지돼요.
