# 이타카로의 귀환 · 도장 기록 백엔드

[이타카로의 귀환](https://h-yun-park.github.io/return-to-ithaca/) 사이트에서 선원이 부스 코드를 넣으면, 이름과 도장 기록이 구글 시트에 쌓여요. 운영진은 시트를 보고 출석 구글폼(도장판 사진)과 이중으로 확인할 수 있어요.

## 동작 방식

1. 선원이 사이트에 처음 들어올 때 이름을 적어요. 휴대폰마다 선원 ID가 하나씩 만들어져요.
2. 부스 활동을 마치면 RA가 그 부스의 4자리 코드를 알려 줘요.
3. 선원이 부스 페이지에 코드를 넣으면 시트의 `선원` 탭에 도장 시각이 찍혀요.
4. 같은 선원이 코드를 10분 안에 5번 틀리면 잠시 막혀요.

## 시트 구성

| 탭 | 내용 |
|---|---|
| 선원 | 선원 1명당 1줄: 이름, 도장 수, 이타카 자격(7개 이상이면 O), 부스별 도장 시각 |
| 부스코드 | 부스별 4자리 코드. 직접 바꿔도 바로 반영돼요 |
| 기록 | 모든 도장 시도 로그(성공, 이미 받음, 코드 틀림) |

## 설치 (처음 한 번)

1. 구글 시트를 새로 만들어요. 예: `이타카로의 귀환 도장 기록`
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 기본 `Code.gs` 내용을 지우고 이 레포의 [`Code.gs`](Code.gs)를 통째로 붙여 넣고 저장해요.
4. 위쪽 함수 선택에서 `setup`을 고르고 **실행**을 눌러요. 권한 허용 창이 뜨면 본인 계정으로 허용해요.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러요.
   - 시트에 `선원`, `부스코드`, `기록` 탭이 생기면 성공이에요.
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해요.
7. 그 URL을 `return-to-ithaca` 레포 `index.html`의 `const API=''` 안에 넣어요.

`Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영돼요. URL은 그대로예요.

## 운영 팁

- 부스 코드는 `부스코드` 탭에만 있어요. 이 레포나 사이트에는 들어가지 않아요. RA에게만 공유하세요.
- 행사 당일 코드가 새어 나가면 `부스코드` 탭에서 바꾸면 돼요.
- 동명이인은 `선원 ID`로 구분돼요. 한 사람이 휴대폰을 바꾸면 새 선원으로 잡혀요.
- 같은 사람이 이름을 다시 등록하면 이름만 바뀌고 도장은 유지돼요.
